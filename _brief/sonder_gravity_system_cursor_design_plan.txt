SONDER DIGITAL CO.
GRAVITY SYSTEM V2
DETAILED CURSOR DESIGN + EXECUTION PLAN

PROJECT PURPOSE

We are creating the new Sonder Digital Co. website as a premium editorial gravity-system experience.

The site should make Sonder Digital Co. feel like a high-level digital experience studio, not a basic web design business, not a generic agency, not a SaaS template, and not a dark sci-fi concept.

The website itself is the proof of the offer.

It should show that Sonder does not simply build websites. Sonder architects digital presence systems that create trust, pull, perception, and momentum.

The visitor should immediately feel:
- This is different.
- This feels expensive.
- This is intentional.
- This is not a template.
- This person understands story, design, motion, trust, and conversion.
- I want my brand to feel like this.

CORE THESIS

MOST BRANDS CHASE ATTENTION.
FEW CREATE GRAVITY.

This line is the entire conceptual anchor.

The website should tell a story about why attention is not enough. Brands do not just need visibility. They need pull. They need a digital world people can enter, understand, trust, remember, and act on.

Sonder Digital Co. is positioned as the studio that designs that pull.

POSITIONING

Sonder Digital Co. should be positioned as a digital experience studio and digital experience architect.

Do not present the company as just a web design studio.
Do not present the company as just a marketing agency.
Do not present the company as just a branding studio.

Sonder sits at the intersection of:
- positioning
- narrative
- interface design
- motion design
- digital systems
- conversion architecture
- brand perception
- online trust

The language should feel elevated, architectural, and precise.

Key positioning sentence:
Sonder Digital Co. engineers digital presence systems that build trust, create pull, and turn perception into momentum.

What this means:
- We clarify the brand.
- We shape the story.
- We design the interface.
- We choreograph the motion.
- We build the conversion path.
- We turn attention into action.

VISUAL IDENTITY

1. BACKGROUND

Main background:
Warm ivory or paper tone.

Use something like:
#F4F0E7
#EEE8DC
#F7F2E8

The background should not be pure white.
It should feel like warm editorial paper.

Add subtle texture only if it stays almost invisible.
Avoid noisy grain that makes the site look fake.
The texture should be soft, premium, and barely there.

2. PRIMARY TEXT

Primary text should be deep black or near black.

Use:
#111111
#171717
#1D1B18

Text should feel sharp, elegant, and serious.

3. GOLD

Gold should be muted, antique, and restrained.

Use:
#9A7A3D
#A98542
#B89A5B
#C1A56B

Gold should appear in:
- nodes
- tiny metadata dots
- select emphasized words
- section indicators
- thin lines
- small progress points
- hover states
- occasional italic type

Gold should never dominate the page.
It should feel like signal, not decoration.

4. LINES

Hairlines are critical.

Use thin rules everywhere:
- section dividers
- orbital diagram paths
- form input lines
- grid markers
- technical diagram axes
- progress lines

Line color:
rgba(17, 17, 17, 0.14)
rgba(154, 122, 61, 0.28)
rgba(17, 17, 17, 0.22)

Lines should be thin, elegant, and calm.

5. DARK SECTION

The final contact section should shift to charcoal/black.

Use:
#151515
#181818
#101010

Typography becomes ivory.
Gold remains muted.

The dark section should feel like a technical mission entry system, not a sci-fi dashboard.

TYPOGRAPHY PRINCIPLES

Typography is the hero of the site.

The site should not rely on many images.
The type should carry the identity.

1. HERO HEADLINES

Use massive serif typography.
The hero headline should feel editorial, almost like a luxury magazine cover.

Use very large type sizes on desktop:
clamp(4rem, 8vw, 10rem)

The line breaks matter.
Do not let the browser create weak automatic breaks.
Set intentional line breaks.

Hero headline:
MOST BRANDS
CHASE ATTENTION.
FEW
CREATE
GRAVITY.

Recommended treatment:
- MOST BRANDS and CHASE ATTENTION in elegant serif uppercase
- FEW CREATE in strong sans or alternate large weight if it creates contrast
- GRAVITY in serif italic or gold-tinted serif
- Period at the end should feel intentional and oversized or carefully placed

The reference images use strong mixed typography:
- huge serif words
- italic serif emphasis
- occasional large sans words
- tiny mono labels

Do the same.

2. EDITORIAL CONTRAST

Mixing type styles is essential.

Use contrast between:
- large serif display type
- italic serif accent type
- condensed uppercase technical labels
- small readable sans body copy
- tiny coordinate metadata

This is what makes the page feel designed instead of generated.

3. SECTION LABELS

Section labels should be tiny, uppercase, tracked out, and technical.

Examples:
01 — SIGNAL
02 — PULL
03 — SHAPE
04 — MOTION
05 — PROOF
06 — CONNECT

Use letter spacing:
0.18em to 0.28em

Use small size:
11px to 13px

They can include a gold node before the label.

4. BODY COPY

Body copy should be short and calm.
No long paragraphs.
No marketing fluff.

Body copy should feel like editorial captions:
- precise
- poetic
- restrained
- strategic

Line height should be generous.
Max width should be narrow.

5. TECHNICAL METADATA

Use small coordinate and system labels throughout.

Examples:
34.052
118.243
MOTION POINT
GRAVITY CORE
POSITIONING
SIGNAL PATH
ORBIT ID: SD-01
ENTRY_01

This gives the site a designed world.
But do not overuse it.

LAYOUT PRINCIPLES

1. EXTREME WHITESPACE

Whitespace is one of the most important design choices.

Do not fill every section.
Do not over-explain.
Do not add cards just because there is empty space.

Whitespace makes the design feel expensive.

Each section should have:
- one dominant idea
- one dominant visual system
- one clear rhythm

2. ASYMMETRY

The layouts should not feel centered and predictable.

Use asymmetrical composition:
- large text on left, diagram on right
- diagrams floating in empty space
- labels offset from headlines
- section captions placed low or high
- horizontal rows with uneven proportions
- visuals cropped or interrupted by rules

Templates feel too balanced.
Editorial systems create tension.

3. GRID BUT NOT OBVIOUS

Use a strong hidden grid.
The visitor should feel precision but not see a basic grid layout.

Possible structure:
12-column desktop grid.
Wide page margins.
Thin rule lines at chapter breaks.
Large vertical spacing.

Use alignment discipline:
- labels align with content edges
- horizontal rules carry across sections
- visual nodes align with text rhythm
- metadata feels intentionally placed

4. FEWER IMAGES, STRONGER IMAGES

Do not add lots of random images.
The references rely mostly on typography, diagrams, and abstract visuals.

Use:
- SVG orbital systems
- abstract architectural frames
- linework panels
- cropped cinematic panels
- gold nodes
- faint wireframes

If images are used, they should feel architectural, abstract, textured, or campaign-like.
No generic agency stock.

5. NO GENERIC CARDS

Avoid typical modern web patterns:
- rounded cards
- icon cards
- three-column service cards
- glassmorphism boxes
- drop-shadow tiles
- dashboard widgets

Services and proof should be presented as editorial rows, diagrams, archives, or technical entries.

SIGNATURE VISUAL SYSTEM: GRAVITY DIAGRAMS

The orbital system is the core visual motif.

It represents:
- attention fields
- perception
- trust
- narrative pull
- the invisible force around a brand
- the structure Sonder creates

It must not look like a planet website.

The orbital diagrams should include:
- thin ellipses
- overlapping orbital paths
- small gold nodes
- occasional black nodes
- dashed lines
- tiny coordinates
- technical labels
- central geometric object
- transparent wireframe shapes
- delicate line intersections

Central object direction:
The hero can include a faceted geometric gravity object, almost like a low-poly crystalline structure or architectural core.
It should feel abstract and premium.
It should not look like a globe, moon, or planet.

Build this with SVG first.
Do not use Three.js yet.
Do not overbuild 3D until the editorial system is correct.

ANIMATION PRINCIPLES

Motion should make the site feel alive and award-winning, but it must stay elegant.

The motion language should be:
- calm
- precise
- cinematic
- slow
- intentional
- premium
- editorial

Avoid:
- spinning planets
- fast parallax
- bouncy animations
- confetti
- random cursor gimmicks
- constant motion everywhere
- heavy particle effects
- glitch effects
- neon trails

Use:
- mask reveals on large headlines
- slow fade/rise section reveals
- subtle orbital drift based on cursor movement
- soft gold node pulse
- line draw animations
- clip-path reveals for panels
- progress line movement while scrolling
- slight parallax on SVG layers
- staggered row reveals
- dark contact form line activation

Motion should feel like a luxury film opening title sequence mixed with an architectural interface.

Cursor drift:
The orbital diagram can subtly respond to cursor movement.
Movement should be extremely small.
Example:
- inner SVG group moves 6px max
- outer orbit moves 12px max
- nodes drift 3px max

Reduced motion:
Always respect prefers-reduced-motion.
If reduced motion is active, disable cursor drift and animated reveals.

CURSOR EXECUTION RULES

Very important:
Do not let Cursor build everything at once.
Build in controlled stages.

Cursor tends to become generic when it does too much at once.
It performs better when asked to:
- implement one section at a time
- follow strict constraints
- self-review against the visual direction
- refine before continuing

Use this workflow:

Step 1:
Set up project structure, tokens, global styles, and components.
No full sections yet.

Step 2:
Build only the hero.
Make the hero exceptional before moving on.

Step 3:
Review the hero against the reference system.
Score it.
Refine typography, spacing, and orbital diagram.

Step 4:
Build Pull and Shape.
Refine Shape heavily because it needs to match the services reference most closely.

Step 5:
Build Motion and Proof.
Avoid generic cards.

Step 6:
Build Connect.
Make it closely follow the dark contact reference.

Step 7:
Polish motion, responsiveness, details, and QA.
