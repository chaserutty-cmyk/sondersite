TYPOGRAPHY SYSTEM
Typography is the hero.

The references rely on massive type, strong contrast, and editorial hierarchy.

Use:
- Huge serif headlines
- Tight uppercase technical labels
- Small mono metadata
- Elegant italic serif accents
- Calm readable body copy

Recommended type direction:
1. Primary headline font: a high-contrast editorial serif.
2. Secondary accent font: italic serif.
3. Metadata font: compact mono or narrow uppercase sans.
4. Body font: clean sans or readable serif/sans pairing.

If premium fonts are not available, use CSS variables so fonts can be swapped later.

Suggested CSS:
--font-serif: "Cormorant Garamond", "Times New Roman", serif;
--font-sans: "Inter", "Helvetica Neue", Arial, sans-serif;
--font-mono: "IBM Plex Mono", "Space Mono", monospace;

Headline rules:
- Use massive scale.
- Use tight line-height.
- Use intentional line breaks.
- Do not make headlines polite.
- Do not let headlines feel like normal web headers.
- Headlines should feel like posters/editorial covers.

Hero headline:

CHASE ATTENTION.
FEW
CREATE
GRAVITY.

The line breaks matter.
The words should feel stacked, sculptural, and spatial.

Suggested desktop headline:

font-weight: 500;

Suggested mobile headline:

LAYOUT PRINCIPLES
The site should not feel built from template sections.

Use editorial composition:

- asymmetric grid
- anchored metadata
- bottom progress lines

- delicate diagrams

Do not:

- add generic hero buttons
- add excessive body copy

SPACING PRINCIPLES
Spacing is a luxury signal.

Use:
- large vertical section padding
- wide horizontal margins
- generous negative space
- sparse metadata
- slow pacing from section to section

Every section should have one dominant idea.

If a section feels busy, remove elements.
If a section feels generic, increase scale, asymmetry, or linework specificity.
If a section feels like a template, remove cards and rebuild with editorial rows, rules, or diagrams.

ORBITAL DIAGRAM SYSTEM
The orbital SVG system is the signature visual language.

It must not look like a planet.
It must not look like sci-fi.
It must not look like an AI-generated glowing orb.

It should look like:
- a technical drawing
- a gravitational map
- a trust system diagram
- a precise editorial SVG object
- a visual metaphor for attention and pull

Elements:
- thin ellipses
- dashed orbit paths
- faint construction lines
- crosshair marks
- small gold nodes
- small black nodes
- coordinate labels
- technical labels
- central geometric object
- subtle diagram imperfections through offsets
- restrained line opacity

Line rules:
- strokes should be very thin
- use black at low opacity
- use gold sparingly
- avoid neon
- avoid glow except very subtle node pulse
- avoid heavy fills

Suggested SVG details:
- 3 to 5 elliptical rings
- 1 dashed ellipse
- 5 to 7 small nodes
- 2 to 4 coordinate labels
- small labels: GRAVITY CORE, MOTION POINT, POSITIONING, TRUST FIELD, SIGNAL PATH
- central object made of SVG lines/polygons, not a sphere
- faint x/y axis line
- tiny tick marks and small technical numerals

MOTION LANGUAGE
The site should use animation to feel award-winning, but not gimmicky.

Motion should feel like luxury film pacing:
- slow
- deliberate
- quiet
- controlled
- precise

Use:
- mask reveals on headlines
- slow fade/rise on copy
- SVG line draw effects
- staggered metadata reveals
- soft gold node pulse
- subtle cursor drift on orbital systems
- gentle parallax on diagrams
- vertical panel reveals
- slight hover movement on case-study rows
- contact field active-state line animation

Do not use:
- spinning planets
- bouncing
- fast transitions
- random hover effects
- over-animated elements
- loading gimmicks
- heavy particle systems

Respect prefers-reduced-motion:
If reduced motion is enabled, remove cursor drift, line draw, parallax, and pulse animations. Preserve layout and readability.
